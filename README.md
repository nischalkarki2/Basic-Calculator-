Basic Calculator
A simple Python calculator that performs basic arithmetic operations.

Features
Addition
Subtraction
Multiplication
Division
Handles invalid inputs
Prevents division by zero
Exit option

How to Run
Make sure Python is installed, then run:
python calculator.py
Follow the menu and enter your choice and numbers.

Example
1. Add
2. Subtract
3. Multiply
4. Divide
5. Exit
Enter an option and the required numbers to get the result.
